# Формула crash-множителя (усечённое Парето)

Справочный лист по формуле, по которой генерируется crash-множитель раунда
(модель `HOUSE_EDGE_V2`). Расширенное описание модели — в
[`crash-math-model.md`](crash-math-model.md).

## Параметры

| Обозначение | Конфиг | Смысл |
|---|---|---|
| `alpha` | `crash.alpha` | наклон / параметр формы, `0 <= alpha < 1` |
| `p` | — | `p = 1 / (1 - alpha)` |
| `min` | `crash.minCrashMultiplier` | нижняя граница, `0 < min <= 1` (для переменного диапазона) |
| `max` | `crash.maxMultiplier` | верхняя граница, `max >= min` |
| `U` | — | равномерное `U ~ Uniform[0, 1)` из детерминированного потока |

## Генерация (inverse CDF)

```text
p = 1 / (1 - alpha)

X = [ U * max^(-p) + (1 - U) * min^(-p) ] ^ (-1 / p)
X_final = floor4(X)   // округление вниз до 4 знаков;
                       // верхняя полоса [max-0.0001, max) включая max (потолок)
```

Это непрерывное усечённое Парето на отрезке `[min, max]` с масштабом `min`
и формой `p`. Верхняя граница достижима: результат из самой верхней
floor4-полосы округляется вверх до `max` (площадь этой полосы пренебрежимо мала).

## Survival-функция

Для `min <= x <= max`:

```text
P(X >= x) = (x^(-p) - max^(-p)) / (min^(-p) - max^(-p))
```

Границы: `P(X >= min) = 1`, `P(X >= max) = 0` в непрерывной модели; перевод
верхней floor4-полосы в `max` добавляет в точку `max` крошечную дискретную массу
`P(X = max) = P(X >= max - 0.0001)`. На нижней границе атома нет: крах `1.0000`
возникает непрерывной полосой `X < 1.0001`.

### Влияние на распределение

Флип верхней полосы **перемещает только массу бина `max - 0.0001` в `max`**;
все остальные исходы и вся survival-функция не меняются. Масса этой полосы для
`min = 1`, `max = 100`:

| alpha | P(X = 100) | примерная частота |
|---:|---:|---:|
| 0.03 | 9.0e-9 | ~1 раунд на 100 млн |
| 0.50 | 2.0e-10 | ~1 на 5 млрд |
| 0.85 | 3.1e-19 | практически никогда |

Из-за этого статистики раундов (P(≥2), P(≥5), P(≥10), средний выигрыш/edge)
не меняются в практическом смысле. Для сравнения, полоса у минимума даёт
`P(X = 1.0000)` ≈ 0.010% (α=0.03), 0.020% (α=0.5), 0.067% (α=0.85) — на 7-12
порядков больше, и именно она формирует «низкий хвост» гистограммы.

## Свойства

- Отображение `[0, 1) -> [min, max]` монотонно: `U = 0` даёт ровно `min`,
  при `U -> 1` результат стремится к `max` снизу и попадает в верхнюю полосу,
  которая округляется вверх до `max` включительно.
- Случай `min == max` возвращает `max` в режиме fixed-range demo/test
  (формула не применяется).
- Больше `alpha` -> меньше `p` -> хвост толще -> больше низких крашей и ниже
  выплаты. Меньше `alpha` -> хвост резче уходит в высокие множители.
- При `alpha = 0` (`p = 1`) формула сводится к гармоническому хвосту:
  `X = 1 / (U/max + (1 - U)/min)` — без возведения в степень, удобна для
  точных проверок.
- Для дробного `p` вычисление идёт в `double` (IEEE-754), один раз округляется
  вниз до 4 знаков (`floor4`); именно это значение сохраняется и входит в
  fairness commitment/reveal.

## Числовые примеры

Для `min = 1`, `max = 100`:

| alpha | p      | P(X >= 2) | P(X >= 5)  | P(X >= 10) |
|---:|---:|---:|---:|---:|
| 0.03 | 1.0309 | ≈ 0.485 | ≈ 0.183 | ≈ 0.085 |
| 0.50 | 2.0000 | ≈ 0.250 | ≈ 0.0400 | ≈ 0.0099 |
| 0.85 | 6.6667 | ≈ 0.0098 | ≈ 2.2e-5 | ≈ 2.2e-7 |

Пример для α = 0.85: P(X >= 2) ≈ 1% — «мгновенных крахов» на границе нет,
но вероятность завершиться рано мала и сосредоточена около нижней границы
непрерывно.

## Ожидание выплаты

Для ставки `B` и фиксированного допустимого target `t`:

```text
E[выплата] = B * t * P(X >= t)
прибыль    = B * (t * P(X >= t) - 1)
```
