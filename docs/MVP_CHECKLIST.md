# MVP checklist

## Обязательное

- [ ] Переключение зелёной/красной темы
- [ ] 9/12 уровней
- [ ] 4 варианта ставки ×1/×2/×3/×4
- [ ] Списание ставки
- [ ] Серверный crash point
- [ ] Рост коэффициента
- [ ] Cashout только после первого уровня
- [ ] Выигрыш = ставка × коэффициент cashout
- [ ] Продолжение полёта после cashout
- [ ] Проигрыш при crash без cashout
- [ ] Серверный выбор уровня бустера
- [ ] Активация бустера до cashout
- [ ] Игровые очки
- [ ] История завершённых игр
- [ ] Экран результата
- [ ] Дополнительная награда по итогам раунда
- [ ] Правила игры
- [ ] Изменение параметров без правки исходного кода
- [ ] Адаптивность 320–1920 px

## После MVP

- [ ] Живой рейтинг
- [ ] Турнирная таблица
- [ ] Upsell «Закрепи успех»
- [ ] Provably fair hash
- [ ] Расширенные анимации и звук
