## Reconnect reducer

`GameSession` subscribes before start. After disconnect it keeps the last UI state read-only, disables cashout, waits for connection, requests bounded replay and then an authoritative cumulative snapshot. Buffered events not newer than snapshot sequence are discarded by the sequence guard; a gap requests another recovery. The REST snapshot, not WebSocket availability or client time, restores business state.

## Integration checklist

1. Merge the frontend branch only after resolving infrastructure files against `integration/backend-core`.
2. Implement server login/current-session and replace the deliberate REAL auth blocker.
3. Map the agreed pre-round catalog/config rather than retaining mock stake constants as facts.
4. Verify exact DTO field names after CORE merges Backend №1 and №2 (`boosterMultiplier` vs persistence tier/value representation).
5. Configure production Nginx/CORS/WebSocket origins and session credentials.
6. Add independent browser-side SHA-256 verification using the saved start commitment and canonical reveal format.
7. Run REAL acceptance with backend scheduler; do not enable automatic retry of start.

## Mock boundaries

MOCK balance starts at 5 000 and changes only inside `MockBackend`: debit on start, credit on cashout. Presets are deterministic UI fixtures, not production math or probability claims. The mock fairness seed is an explicit fixed example and is never generated by React.
