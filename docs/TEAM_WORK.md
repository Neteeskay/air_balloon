# Работа команды

Рекомендуемая параллельная работа:

- Frontend: экраны, компоненты, анимация, состояние клиента
- Backend/Game: игровой движок, crash, booster, points, WebSocket
- Backend/Data: пользователи, баланс, история, настройки, PostgreSQL
- Design: визуальный стиль, шар, уровни, состояния, эффекты
- QA/Integration: обязательные сценарии 1–5 и сквозная проверка

Перед объединением крупной функциональности фиксировать API/события в `docs/API_CONTRACT.md`.
