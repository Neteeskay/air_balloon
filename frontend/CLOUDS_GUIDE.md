# Гайд по добавлению облаков на лендинг

## Архитектура

Облака расположены в `src/features/landing/pages/LandingPage.tsx` и разделены на 3 слоя:

| Слой | Константа | Спрайты | Описание |
|------|-----------|---------|----------|
| Far | `FAR_CLOUDS` | 12-16 | Маленькие, размытые, медленный parallax |
| Middle | `MIDDLE_CLOUDS` | 8-11 | Средние, заметный parallax |
| Near (intro) | `INTRO_CLOUDS` | 1-7 | Крупные, появляются при загрузке, разлетаются при скролле |

## Структура облака

```typescript
{
  id: 'in-l1',      // Уникальный ID
  x: -6,            // Позиция X (% от ширины viewport)
  y: 8,             // Позиция Y (% от высоты viewport)
  scale: 0.85,      // Масштаб спрайта
  cloudNum: 1,      // Номер спрайта (1-16)
  delay: 0,         // Задержка появления (сек) — только для intro
}
```

## Координаты

- `x: 0%` = левый край, `x: 100%` = правый край
- `y: 0%` = верх, `y: 100%` = низ
- Отрицательные x/y = за пределами viewport (используется для fly-in)

## Распределение по слоям

### Intro clouds (near) — 13 облаков
- **Левая сторона**: `x: -6` до `-3`, `y: 8` до `86`
- **Правая сторона**: `x: 87` до `91`, `y: 6` до `84`
- **Верх**: `x: 18` до `74`, `y: -7` до `-5`
- Спрайты: крупные (1-7)
- Анимация: fly-in при загрузке → scatter при скролле

### Far clouds — 10 облаков
- Края viewport: `x: 2` до `7` (лево), `x: 87` до `93` (право)
- Распределены по высоте: `y: 12` до `145` (часть за viewport)
- Спрайты: маленькие (12-16)
- Parallax factor: 0.15

### Middle clouds — 8 облаков
- Края viewport: `x: 1` до `5` (лево), `x: 88` до `93` (право)
- Распределены по высоте: `y: 18` до `130`
- Спрайты: средние (8-11)
- Parallax factor: 0.45

## Как работает анимация

1. **Загрузка**: Intro облака летят с краёв экрана к позициям (time-based, 2с)
2. **Скролл**: Только «первый экран» (top-облака, `y <= 33`) разлетается в стороны (scrub, 0-30% scroll): левые улетают за левый край, правые — за правый, с лёгким подъёмом, поворотом и затуханием. При возврате наверх scrub отыгрывается в обратную сторону — облака снова налетают
3. **Parallax**: Остальные слои (far, middle, intro ниже первого экрана) двигаются вверх с разной скоростью:
   - Far: `pageHeight × 0.15`
   - Middle: `pageHeight × 0.45`
   - Near: `pageHeight × 1.0`

## Добавление нового спрайта

1. Поместите PNG в `public/sprites/cloud-17.png`
2. Добавьте в `src/features/landing/config/sprites.ts`:
```typescript
17: '/sprites/cloud-17.png',
```
3. Обновите тип `cloudNum` в `LandingPage.tsx`:
```typescript
cloudNum: 1 | 2 | ... | 17;
```
