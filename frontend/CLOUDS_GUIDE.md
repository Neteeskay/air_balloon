# Гайд по добавлению облаков на лендинг

## Где находятся облака

Файл: `src/features/landing/pages/LandingPage.tsx`

Массив облаков: `INTRO_CLOUDS`

## Структура облака

```typescript
{
  id: 'intro-1',      // Уникальный ID
  x: -30,             // Позиция X (в процентах)
  y: 8,               // Позиция Y (в процентах)
  scale: 0.7,         // Размер облака
  cloudNum: 1         // Номер спрайта (1-16)
}
```

## Координаты для спавна

### Слева (облака наплывают справа)
- `x: -25` до `-35` (чем меньше, тем дальше за экраном)
- `y: 0` до `100` (любая высота)

### Справа (облака наплывают слева)
- `x: 125` до `136` (чем больше, тем дальше за экраном)
- `y: 0` до `100` (любая высота)

### Сверху (облака наплывают снизу)
- `x: 0` до `100` (любая ширина)
- `y: -18` до `-30` (чем меньше, тем выше за экраном)

### Снизу (облака наплывают сверху)
- `x: 0` до `100` (любая ширина)
- `y: 118` до `130` (чем больше, тем ниже за экраном)

## Параметры

### Scale (размер)
- `0.5` - маленькое облако
- `0.7` - среднее облако
- `1.0` - большое облако

Рекомендуется: `0.6` - `0.75`

### CloudNum (номер спрайта)
Доступные спрайты: `1` - `16`

- Спрайты 1-7: крупные облака
- Спрайты 8-11: средние облака
- Спрайты 12-16: маленькие облака

## Как работает анимация

1. **Старт**: Облака находятся за экраном (координаты выше)
2. **Вход**: Все облака ОДНОВРЕМЕННО (за 1.5 сек) двигаются к центру:
   - Слева → +15% вправо
   - Справа → -15% влево
   - Сверху → +12% вниз
   - Снизу → -12% вверх
3. **Скролл**: При прокрутке облака уходят обратно за экран

## Советы по размещению

### Равномерное распределение
Располагайте облака равномерно по всем 4 сторонам:
- Слева: 5-6 облаков
- Справа: 5-6 облаков
- Сверху: 4-5 облаков
- Снизу: 4-5 облаков

### Вариация размеров
Чередуйте размеры для визуального разнообразия:
```typescript
scale: 0.65, // маленькое
scale: 0.72, // большое
scale: 0.68, // среднее
```

### Вариация спрайтов
Используйте разные номера облаков, чтобы избежать повторений

## Изменение анимации

Если нужно изменить параметры анимации, редактируйте в `useEffect`:

```typescript
gsap.to(cloud, {
  x: targetX + '%',
  y: targetY + '%',
  opacity: 1,
  duration: 1.5,        // Скорость входа (секунды)
  ease: 'power2.out',   // Тип easing
});
```

### Параметры движения к центру

```typescript
if (cloudData.x < 0) {
  targetX = 15; // Слева: насколько глубоко к центру (%)
}
if (cloudData.y < 0) {
  targetY = 12; // Сверху: насколько глубоко к центру (%)
}
```

Увеличьте числа → облака заходят глубже
Уменьшите числа → облака остаются у краёв

## Добавление новых спрайтов

Если хотите добавить новые изображения облаков:

1. Поместите PNG файл в `public/sprites/`
2. Назовите его `cloud-17.png` (следующий номер)
3. Добавьте в `src/features/landing/config/sprites.ts`:
```typescript
17: '/sprites/cloud-17.png',
```
4. Обновите тип в `CloudLayer.tsx`:
```typescript
cloudNum: 1 | 2 | ... | 17;
```
